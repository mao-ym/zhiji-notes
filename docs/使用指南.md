# 使用指南

## 安装与启动

在 PowerShell 中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
$env:WRITING_LIBRARY_ROOT = "D:\\WritingLibrary"
python -m writing_companion.cli serve --library $env:WRITING_LIBRARY_ROOT
```

服务默认监听 `127.0.0.1:8765`。启动后在浏览器打开 `http://127.0.0.1:8765`。

如已安装命令入口，也可以运行：

```powershell
writing-companion serve --library $env:WRITING_LIBRARY_ROOT
```

## 资料库目录

`--library` 指向的目录是唯一的数据根目录。应用会在其中创建：

```text
D:\WritingLibrary\
├─ documents\
│  ├─ diary\       日记 Markdown
│  ├─ fragments\   片段 Markdown
│  └─ works\       作品 Markdown
├─ database\
│  └─ writing.db   SQLite 索引、状态和本地任务队列
├─ attachments\    附件
├─ exports\        导出物
└─ backups\        每日备份和恢复前快照
```

正文、数据库、附件、导出物、备份和恢复副本都位于资料库根目录内。手机投递时使用的 `.mobile-staging` 是临时目录，接收成功后会被清理或转为正式 Markdown 文件。

## API Key 与隐私

电脑端“API 设置”中的 API Key 只会写入 Windows 凭据管理器，不会写入 Markdown、SQLite、日志、导出物或普通配置文件。

陪聊、问候和记忆提取只会使用未锁定且允许 AI 使用的内容。锁定文稿仍可被本地搜索，但不会进入新的对话、问候或记忆提取上下文。

## 局域网接收开关

局域网接收默认关闭。使用 `serve --lan` 才会绑定 `0.0.0.0`，允许同一私有 Wi-Fi 的手机访问；电脑端接口仍只对本机开放，局域网客户端只能访问手机页面和手机上传接口。不要在公网或不可信网络中启用该模式。

手机入口是 `/mobile/`。它只接收新内容，不提供读取、修改或删除电脑现有文稿的接口。

## 备份与恢复

每日备份保存为：

```text
D:\WritingLibrary\backups\YYYY-MM-DD.zip
```

归档包含 `documents/`、SQLite 快照 `database/writing.db` 和 `attachments/`。同一天的备份是幂等的，默认保留最近 30 天；创建失败不会留下可被误认为有效备份的临时 ZIP。

从备份创建恢复副本时，当前库会先保存为：

```text
D:\WritingLibrary\backups\当前库-恢复前-<时间戳>.zip
```

然后解压到资料库根目录内的：

```text
D:\WritingLibrary\<备份名>-恢复-<时间戳>\
```

恢复是创建副本，不会覆盖当前库。也可以使用下方命令从已有 Markdown 重建索引：

```powershell
python -m writing_companion.cli rebuild-index --library $env:WRITING_LIBRARY_ROOT
```

## 手机端离线投递

手机 PWA 会先把新内容写入浏览器的本地待发送箱，再尝试上传。网络中断、服务端错误或回执不匹配时，这条内容会保留；点击“同步”或恢复网络后会继续发送。只有收到与提交和文档都匹配的确认回执，待发送箱才会删除该条内容。

服务端会安全处理相同提交的重复上传，只创建一份文档和一条记忆任务。手机不会下载电脑资料库中的内容。

## 网络不可用时仍可使用的能力

- 新建、编辑和每 60 秒自动保存日记、片段和作品。
- 本地全文搜索，包括锁定文稿。
- 附件落盘、Markdown 引用、导出和 SQLite 索引重建。
- 每日备份、恢复前快照和恢复副本。
- 本地任务队列会保留 AI/记忆任务，模型可用后再重试。
- 手机 PWA 可以离线创建内容，并在网络恢复后重试发送。

远程模型生成、连接测试和在线陪聊需要可用的 API 配置与网络；它们失败不会阻塞本地资料库操作。

## 手机端局域网使用

电脑和手机连接同一个可信 Wi-Fi 后，在电脑上启动局域网模式：

```powershell
. .\.venv\Scripts\Activate.ps1
$env:WRITING_LIBRARY_ROOT = "D:\\WritingLibrary"
python -m writing_companion.cli serve --library $env:WRITING_LIBRARY_ROOT --lan
```

启动后，命令行会显示类似 `http://192.168.1.20:8765/mobile/` 的手机访问地址。在手机浏览器打开该地址；第一次应在电脑开机且网络正常时打开，以便缓存 PWA 静态资源。

手机端只负责新建日记、片段和作品并上传，不读取电脑已有文档。电脑关机或网络中断时，页面仍可记录内容，内容会保存在手机本地待发送箱；电脑重新开机后打开页面并点击“立即同步”，或等待网络恢复自动同步。

`--lan` 会让同一局域网内的设备访问服务，只应在可信私有 Wi-Fi 中使用，不要在公网或不可信网络中启用。若命令行没有找到地址，可在电脑执行 `ipconfig`，使用无线网卡的 IPv4 地址替换 URL 中的地址。

首次启动时如果 Windows Defender 防火墙弹窗询问网络访问权限，只允许“专用网络”；如果手机仍无法连接，请检查电脑和手机是否在同一 Wi-Fi，以及防火墙是否阻止了 Python 服务。
